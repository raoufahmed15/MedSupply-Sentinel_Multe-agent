# MedSupply Sentinel — Synthetic Demo Data

This folder contains all data required by the Kaggle notebook.

- synthetic/medications.csv
- synthetic/inventory.csv
- synthetic/suppliers.csv
- synthetic/shortage_events.csv
- synthetic/synthetic_patients.csv
- mock_api/M001.json ... M004.json
- guidelines/*.pdf
- config/demo_scenario.json

All patient records are synthetic. The PDFs are demonstration operational documents, not real clinical guidelines.

The notebook also generates an equivalent dataset automatically under `/kaggle/working/medsupply_sentinel/data` so you do NOT have to upload this dataset to Kaggle.
